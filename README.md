# 🕹️ TP1: Hit and Run - Fundamentos de Programación

¡Bienvenido al repositorio del Trabajo Práctico N°1! Este proyecto consiste en el desarrollo de un juego interactivo por consola desarrollado en **lenguaje C**, enfocado en el uso correcto de estructuras de datos fijas, manejo de memoria, matrices dinámicas/estáticas y lógica de juego por turnos.

## 🚀 Características principales
- **Tablero Dinámico:** Representación de mapas por consola con validación de colisiones (monorriel, obstáculos y personajes).
- **Control de Estado:** Estructuras dedicadas (`juego_t`) para mantener el flujo limpio de datos y punteros.
- **Automatización:** Compilación optimizada mediante un archivo `Makefile`.

## 🛠️ Compilación y Ejecución

Para compilar y ejecutar el proyecto localmente, asegúrate de tener instalado el compilador `gcc` y la herramienta `make`.

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com
   cd TP1-HIT-AND-RUN-Fundamentos
   ```

2. **Compilar el proyecto:**
   ```bash
   make compilar
   ```

3. **Ejecutar el juego:**
   ```bash
   ./juegohit
   ```
